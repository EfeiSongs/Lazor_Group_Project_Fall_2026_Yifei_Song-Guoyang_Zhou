USER GUIDE

1. What is this?
· The Lazor Group Project project was jointly completed by Yifei Song and Guoyang Zhou.

2. System Requirements
· Python 3 or higher version must be installed on the computer.

3. Running and Testing the Program
· Decompress the compressed file completely into a folder.
· If you need to solve the light path problem in the bff file, only run lazor.py. You need to modify the file name of the bff file that needs to be solved in the code (line 16).
·  Running generate_bff.py will obtain a bff maze file with a specified name.
